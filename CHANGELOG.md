# История изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [1.0.0] — 2026-11-24

Первый стабильный релиз.

### Добавлено
- Иконка приложения (генератор `tools/make_icon.swift`).
- Документация: README, руководство пользователя, форматы обоев, архитектура.

## [0.9.0-beta] — 2026-11-24

Полный функционал и редизайн, без иконки и документации.

### Возможности
- Движок рабочего стола: видео, веб, картинки и GIF, слайдшоу, GLSL-шейдеры, сцены; несколько мониторов и режим «растянуть».
- API веб-обоев Wallpaper Engine, импорт проектов из мастерской Steam и загрузка через steamcmd.
- Редактор сцен: слои, частицы, параллакс, волны, свечение, цветокоррекция, часы и дата.
- Реакция на системный звук (ScreenCaptureKit + vDSP FFT).
- Библиотека с тегами и избранным, плейлисты по таймеру и времени суток, пакеты `.wallpkg`, автозапуск.
- Угольно-алый дизайн: свой сайдбар с мини-плеером, анимированные карточки и чипы, заставка, условия использования, титры, онбординг из 7 страниц.

### Производительность
- Нагрузка сцены снижена примерно с 42 % до 6 % CPU:
  - лимит 15 FPS по умолчанию и адаптивное ускорение до 30 FPS при движении мыши;
  - рендер в 1×, непрозрачный WebView, без `preserveDrawingBuffer`;
  - пауза, когда рабочий стол закрыт окнами на ≥85 %;
  - выгрузка интерфейса SwiftUI, когда окно закрыто.

### Исправлено
- WebKit не вызывал `requestAnimationFrame` в окне рабочего стола — добавлен собственный планировщик кадров.
- Назначенные обои сбрасывались при запуске.
- Глобальный перехват мыши запрашивал «Универсальный доступ» — курсор теперь опрашивается без разрешений.
